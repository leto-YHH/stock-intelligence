# 產業評分模型說明

## 概念

系統每週對台灣主要產業計算綜合評分，篩選出 3–5 個最具潛力的產業，再進入個股篩選階段。

評分結果依使用者選定的持股週期（1 個月 / 3 個月 / 1 年）給予不同維度權重，同一個產業在短線和長線的推薦結果可能完全不同。

---

## 五個評分維度

### 1. 資金流向（Capital Flow）

**衡量什麼：** 機構資金是否正在流入這個產業

**資料來源：** 台灣證交所每日公告、FinMind API

**計算邏輯：**
- 加總產業內所有個股的外資買賣超金額
- 加總投信買賣超金額
- 與過去四週平均比較，算出資金動能分數
- 連續買超天數作為加分項

**實證依據：**
機構投資人的持續買進行為（Institutional Momentum）在接下來 4–8 週對股價有顯著預測力。台灣外資佔市值約 40%，外資方向幾乎決定大型股走勢。

**有效週期：** 1–2 個月（短線最重要的維度）

---

### 2. 新聞情緒（News Sentiment）

**衡量什麼：** 市場對這個產業的情緒偏向

**資料來源：** RSS Feed（鉅亨網、經濟日報）+ Claude API 情緒分析

**計算邏輯：**
- 每篇新聞給予 -1.0 到 +1.0 的情緒分數
- 依新聞中提到的產業關鍵字，把分數分配到對應產業
- 用過去 5 個交易日的加權平均（越近越重）
- 台灣新聞和美國新聞分開計算，再合併

**產業關鍵字對應範例：**
```
半導體：台積電、聯發科、晶圓、AI 晶片、HBM、CoWoS
金融：升息、降息、銀行、壽險、Fed
航運：BDI、貨櫃、長榮、散貨
```

**實證依據：**
新聞情緒的效果會在 2–4 週內被市場消化。負面新聞衝擊速度快於正面新聞（損失趨避效應），需要在計算中給負面情緒稍高的權重。

**有效週期：** 2–4 週（短中線有效，長線為雜訊）

---

### 3. 相對強度（Relative Strength）

**衡量什麼：** 這個產業相對大盤是強還是弱

**資料來源：** yfinance（個股日線資料）

**計算邏輯：**
- 計算產業平均漲跌幅（等權重）
- 減去同期加權指數漲跌幅
- 分別算 4 週相對強度和 12 週相對強度
- 加權合併：4 週佔 60%，12 週佔 40%

**實證依據：**
動能效應（Momentum Effect）是財務學中少數被跨市場廣泛複製的異常現象。在美股、歐股、台股均有實證：過去 3–12 個月表現強的資產，接下來 3–12 個月繼續強的機率高於隨機（Jegadeesh & Titman 1993；後續多篇台股研究均複製此效應）。

**有效週期：** 3 個月–1 年（中線最可靠的維度之一）

---

### 4. 美國連動指數（US Correlation Index）

**衡量什麼：** 台灣產業對應的美國領先指標強弱

**資料來源：** yfinance

**台灣產業 ↔ 美國指數對應表：**

| 台灣產業 | 美國對應指標 | 代碼 |
|---------|------------|------|
| 半導體 | 費城半導體指數 | ^SOX |
| 科技整體 | Nasdaq 100 | ^NDX |
| 金融 | KBW 銀行指數 | ^BKX |
| 航運（散貨）| 波羅的海乾散貨 | BDI（需特殊來源）|
| 電動車 | 全球電動車 ETF | DRIV |
| 生技 | 那斯達克生技 | ^NBI |
| 鋼鐵原物料 | 原物料 ETF | XLB |

**計算邏輯：**
- 抓取美國對應指數最近 5 個交易日表現
- 計算其相對 S&P 500 的強度
- 作為台灣對應產業的領先指標（領先 1–3 個交易日）

**實證依據：**
台灣半導體與費城半導體指數的相關係數長期在 0.7 以上。美國盤收盤後的走向，通常在隔日台灣開盤時反映。

**有效週期：** 短中線均有效（領先效果在 1–2 週內）

---

### 5. 基本面趨勢（Fundamental Trend）

**衡量什麼：** 這個產業的企業獲利動能是加速還是減速

**資料來源：** 公開資訊觀測站（月營收）、FinMind API（財務報表）

**計算邏輯：**
- 計算產業內所有個股的月營收年增率（YoY）
- 比較最近三個月平均 YoY vs 前三個月平均 YoY
- 加速成長（momentum accelerating）為正分，減速為負分
- 每月 10 號公告後更新

**台股特殊優勢：**
台股強制每月 10 號公告月營收，是全球少有的高頻基本面資料更新機制。相較於美股每季財報，台股基本面資訊更新頻率高 3 倍，可以更早捕捉到企業動能的轉折。

**實證依據：**
月營收年增率加速是長線股價的最可靠領先指標之一。台股研究顯示，連續三個月以上月營收創高的個股，一年後的平均報酬顯著高於大盤。

**有效週期：** 6 個月–1 年（長線最重要的維度）

## 加權計算公式

```python
def calculate_industry_score(scores: dict, period: str) -> float:
    """
    scores = {
        'capital_flow':      0~100,
        'news_sentiment':    0~100,
        'relative_strength': 0~100,
        'us_correlation':    0~100,
        'fundamentals':      0~100,
    }
    period = '1m' | '3m' | '1y'
    """
    weights = {
        '1m': {
            'capital_flow': 0.35,
            'news_sentiment': 0.30,
            'relative_strength': 0.20,
            'us_correlation': 0.15,
            'fundamentals': 0.00,
        },
        '3m': {
            'capital_flow': 0.20,
            'news_sentiment': 0.15,
            'relative_strength': 0.30,
            'us_correlation': 0.20,
            'fundamentals': 0.15,
        },
        '1y': {
            'capital_flow': 0.10,
            'news_sentiment': 0.05,
            'relative_strength': 0.20,
            'us_correlation': 0.15,
            'fundamentals': 0.50,
        },
    }
    w = weights[period]
    return sum(scores[k] * w[k] for k in scores)
```
