# 個股篩選邏輯說明

## 概念

產業評分選出 3–5 個潛力產業後，進入個股篩選。一個產業可能有 30–100 檔股票，目標是縮小到 3–5 檔值得推薦的個股。

篩選分三層，依序執行：

```
候選個股（產業內全部）
    │
    ▼ 第一層：硬條件過濾
排除不適合的股票（流動性差、財務問題）
    │
    ▼ 第二層：動能評分
剩餘個股打分排名
    │
    ▼ 第三層：週期適配回測
確認這檔股票在目標週期的歷史表現
    │
    ▼
推薦名單（3–5 檔）
```

---

## 第一層：硬條件過濾

不符合以下任一條件，直接排除，不進入評分階段。

### 流動性條件
- 近 20 個交易日日均成交額 ≥ **3,000 萬元**
- 理由：成交量太低的股票進出成本高，且容易被少數資金操控

### 財務健康條件
- 最近兩季 EPS 均不虧損（EPS > 0）
- 負債比 ≤ 60%
- 理由：排除地雷股，避免基本面劣化的股票混入推薦名單

### 市值條件（依週期調整）
| 持股週期 | 最低市值門檻 |
|---------|------------|
| 1 個月 | 30 億元以上 |
| 3 個月 | 50 億元以上 |
| 1 年 | 100 億元以上 |

長線不推薦小型股，因為小型股流動性和資訊透明度較低，長期持有風險較高。

---

## 第二層：動能評分

通過第一層的個股，進行三個子維度的評分，各 0–100 分，加總後排名。

### 子維度 A：價格動能

計算個股相對產業平均的超額報酬：

```
價格動能分數 =
    近 1 個月超額報酬 × 0.5 +
    近 3 個月超額報酬 × 0.3 +
    近 6 個月超額報酬 × 0.2
```

超額報酬 = 個股漲幅 - 產業平均漲幅

強於產業平均越多，分數越高。

### 子維度 B：籌碼集中度

外資和投信的買超狀況：

```
籌碼分數 =
    外資近 10 日買超張數排名（產業內）× 0.6 +
    投信近 10 日買超張數排名（產業內）× 0.4
```

排名轉換為 0–100 分（產業內第 1 名 = 100 分）。

### 子維度 C：營收動能

```
營收動能分數 =
    最近 3 個月 YoY 平均 > 前 3 個月 YoY 平均 → 加速成長（高分）
    最近 3 個月 YoY 平均 < 前 3 個月 YoY 平均 → 減速（低分）
    連續月營收創新高 → 額外加分
```

### 動能總分合成

```python
momentum_score = (
    price_momentum   × 0.40 +
    chip_score       × 0.35 +
    revenue_momentum × 0.25
)
```

取動能總分前 10–15 名，進入第三層。

---

## 第三層：週期適配回測

這是整個系統最核心、也最有區分度的一層。

### 核心概念

對每檔個股，計算「過去持有 N 天的滾動勝率和平均報酬」。不是用全部歷史資料算一個固定數字，而是用**滾動視窗**，避免過擬合。

### 計算流程

```python
def rolling_backtest(stock: str, hold_days: int, window_weeks: int = 52) -> dict:
    """
    stock      : 個股代碼
    hold_days  : 持有天數（30 / 90 / 250）
    window_weeks: 回測視窗（預設一年）

    回傳：
        win_rate   : 勝率（持有 hold_days 後為正報酬的比例）
        avg_return : 平均報酬率
        stability  : 報酬標準差（越低越穩定）
    """
```

### 持有天數對應

| 使用者選擇 | 持有天數（交易日）|
|-----------|----------------|
| 1 個月 | 22 個交易日 |
| 3 個月 | 66 個交易日 |
| 1 年 | 250 個交易日 |

### 通過標準

| 持股週期 | 最低勝率 | 最低平均報酬 |
|---------|---------|------------|
| 1 個月 | 55% | +3% |
| 3 個月 | 55% | +6% |
| 1 年 | 60% | +12% |

未達標準的個股不進入推薦名單，寧缺勿濫。

---

## 最終推薦輸出

每個產業推薦 1–2 檔個股，合計全系統推薦 3–8 檔。

每檔推薦附上：

```json
{
  "symbol": "2330",
  "name": "台積電",
  "industry": "半導體",
  "period": "3m",
  "momentum_score": 87.3,
  "backtest": {
    "win_rate": 0.68,
    "avg_return": 0.112,
    "hold_days": 66
  },
  "reasons": [
    "外資連續 8 日買超，居半導體族群第 1",
    "近 3 個月月營收年增率加速（+42% → +61%）",
    "費城半導體指數強勢帶動",
    "過去一年持有 66 天勝率 68%，平均報酬 +11.2%"
  ]
}
```

---

## 注意事項

- 回測結果為歷史資料，不保證未來表現
- 建議搭配每日 Dashboard 的市場情緒，在大盤極度恐慌時暫停進場
- 個股推薦每週更新一次，不建議每天頻繁操作
